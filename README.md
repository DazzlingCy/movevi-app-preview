# Movevi App 预览版

Movevi 是一款围绕城市跑步探索打造的移动端体验原型。首页以世界地图为核心，通过城市点亮、路线进度和活动任务，引导用户持续探索不同城市。

[在线预览](https://dazzlingcy.github.io/movevi-app-preview/)

## 主要功能

- 交互式城市地图与四种城市状态
- 当前城市路线进度和城市探索入口
- 点亮记录、排行榜与每日任务
- 热门活动快捷入口与奖励提示
- 面向移动端优化的深色玻璃质感界面

## 技术栈

- React 19
- TypeScript
- Vite 6
- Tailwind CSS 4
- Motion

## 本地运行

需要安装 Node.js 18 或更高版本。当前预览版无需配置 API Key。

```bash
npm install
npm run dev
```

默认开发地址为 `http://localhost:3000`。

## 可用命令

```bash
npm run lint    # TypeScript 类型检查
npm run build   # 生产构建
npm run preview # 预览生产构建
```
