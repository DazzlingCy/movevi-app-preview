# MOVEVI 木卫六 App 2.0

独立的新版本原型，依据《MOVEVI 木卫六极简环球旅程 PRD V1.0.0》实现。老项目不在本目录内，本项目的修改不会覆盖老版本。

在线预览：[https://dazzlingcy.github.io/movevi-app-2.0/](https://dazzlingcy.github.io/movevi-app-2.0/)

## 产品主线

今天跑哪里 → 发现路线 → 完成城市 → 选择下一站。

- 首页城市卡片支持左右滑动，并根据城市状态进入旅程。
- 世界地图展示已完成、当前、候选与等待探索城市，并提供全球城市列表。
- 底部保留“今日 / 世界 / 活动 / 我的”四项导航，活动与个人内容延续老版本。
- 每城 10 条路线，按完成 3/6/10 条分阶段开放。
- 新开放路线先以“未知路线”出现，点击后揭晓。
- 第 1–9 条新路线进入路线完成页，第 10 条直接进入城市完成页。
- 城市完成后从四个候选城市中选择下一站，并播放航迹与护照印章动效。
- 账号、设备、设置与帮助保留为顶部轻入口。

刷新页面会恢复演示状态：北京、上海已完成，东京完成 6/10，已发现 128 处景点。

## 本地运行

```bash
npm install
npm run dev
```

默认访问 `http://127.0.0.1:3000/`。

## 验证

```bash
npm test
npm run lint
npm run build
```

`npm test` 覆盖 20 城/200 路线内容校验、3/6/10 阈值、任意顺序、未知路线揭晓、幂等完成、城市完成候选和下一站切换。
